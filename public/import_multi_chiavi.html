01 — Seleziona file Excel

Il file può contenere più fornitori: ogni riga indica il suo fornitore nella colonna FORNITORE. Colonne del listino standard (ART, DESCRIZIONE, UM, PREZZO, SCONTO1, SCONTO2, CAT MERCE, EAN, FORNITORE, DATA ULTIMO AGGIORNAMENTO) più le colonne foto FOTO1 … FOTO10 (oppure una sola colonna FOTO con più nomi separati da ;), con il nome esatto del file (es. ART123.jpg). Ogni articolo accetta fino a 10 foto generiche. Le celle vuote restano vuote e non vengono mostrate nella ricerca.

02 — Foto articoli (opzionale)

Seleziona o trascina insieme tutte le foto del file, di tutti i fornitori. Ogni foto viene abbinata agli articoli tramite il nome file scritto nelle colonne FOTO (massimo 10 foto per articolo). Le foto vengono raggruppate in una cartella per fornitore: ad ogni nuovo import le foto precedenti di ogni fornitore presente nel file vengono rimosse e sostituite con quelle caricate qui, esattamente come avviene per i dati del listino.

03 — Avvia importazione

Tutti i record e le foto esistenti di ciascun fornitore presente nel file verranno eliminati e sostituiti con i dati e le foto caricati qui. I fornitori non presenti nel file non vengono toccati.
